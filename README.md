# WarmaneMods
All the mods, patches you're going to need on this server.

## HD Client
You can download the HD client from the discord server of the people who actively maintain it [here](https://discord.gg/Gyb9Z252vt).<br/>
To fix the mouse cursor issues that come with this specific client you should download and use [this executable](https://github.com/NecturaLabs/WarmaneMods/blob/main/Game%20Executable/HD%20Client%20Cursor%20Fix.zip).

## Safety Warning - Read before downloading Game Executables
When downloading executables online you are **ENCOURAGED** to scan them on VirusTotal first before running:
